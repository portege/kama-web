Activity Log

A comprehensive audit trail of all data-modifying operations — who did what, when, and from where.

Restricted Access

The Activity Log is available only to superadmin.

How It Works

BABEH automatically logs all POST, PUT, and DELETE requests (except query endpoints) via middleware. Logging is passive and requires no manual action.

What Is Logged

FieldDescription
TimestampWhen the request was processed
UserUsername extracted from JWT. API-key users labeled as api_user, unauthenticated as anonymous
MethodHTTP method: POST, PUT, or DELETE (GET requests are not logged)
EndpointFull request path
Status CodeHTTP response status (200, 400, 401, 500, etc.)
DurationRequest processing time in milliseconds
PayloadSanitized request body (sensitive fields are masked)
ResultSanitized response body
IP AddressClient IP (supports X-Forwarded-For for proxied requests)
User AgentBrowser/client user agent string
Device TypeDesktop, Mobile, or Tablet
OSOperating system (with version)
BrowserBrowser name (with version)
ErrorError message (if the request failed)

Security Measures

Payload Sanitization
  • Login payloads are fully redacted — password fields never appear in logs
  • Sensitive fields (password, token, secret, etc.) in other payloads are masked to ***
  • Large payloads may be truncated to prevent excessive storage

Activity Log Table

Screenshot: Activity log table with method badges, status code badges, and filter controls

Table Columns

  • ID — Log entry number
  • Timestamp — Date and time (sortable)
  • User — Who performed the action (sortable)
  • Method — Color-coded badge: POST PUT DELETE
  • Endpoint — The API path called (sortable)
  • Status — Color-coded status badge (green for 2xx, yellow for 4xx, red for 5xx)
  • Duration — Processing time in ms (sortable)
  • IP — Client IP address

Filtering & Sorting

  • Search — Free-text search across user, endpoint, and IP
  • Method filter — Dropdown: All, POST, PUT, DELETE
  • Date range — Start and end date pickers
  • Column sorting — Click headers to sort by timestamp, user, method, endpoint, status, or duration
  • Page size — 25, 50, or 100 entries per page

Detail Modal

Click any row to see the full log entry, including:

  • Full sanitized request payload
  • Full sanitized response result
  • Error message (if applicable)
  • Device info — type, OS, browser, user agent

Data Retention

Automatic Purge

Activity log entries older than 120 days are automatically purged on server startup. This retention period is configured in the system (default: ACTIVITY_LOG_RETENTION_DAYS = 120).

Export

Click "Export CSV" to download the current filtered view as a CSV file for external audit, compliance, or analysis purposes.

API Reference

All BABEH REST API endpoints. Base URL: /api. Admin endpoints: /api/admin. Click any endpoint to expand details, fields, and sample payloads.

Authentication

Public API endpoints require an API Key header:

X-API-Key: your_api_key_here

Admin endpoints require a JWT Bearer token from POST /api/admin/login:

Authorization: Bearer <token>
Interactive Docs

Auto-generated Swagger UI at /docs and ReDoc at /redoc are available when the server is running.

Query

POST /api/query Submit a question, get a full JSON response ▶

Runs the full search pipeline and returns an LLM-generated answer with citations.

Request Body (JSON)
FieldTypeRequiredDescription
querystringRequiredThe user's natural-language question
search_typestringOptionalOverride search method: hybrid, vector, bm25
top_kintegerOptionalMax chunks to retrieve (default from admin settings)
Sample Request
{ "query": "What are the features of Product X?", "search_type": "hybrid", "top_k": 5 }
Sample Response
{ "query": "What are the features of Product X?", "llm_response": "Product X includes features A, B, and C [1].", "results": [ /* search hit objects */ ], "total_results": 3, "processing_time": 0.42, "search_type": "hybrid" }
200 OK 400 Query too long 401 Missing API key 429 Quota exceeded
POST /api/query/stream Streaming query via Server-Sent Events ▶

Same pipeline as /query but streams the LLM response token-by-token. Returns text/event-stream.

Request Body (JSON)
FieldTypeRequiredDescription
querystringRequiredThe user's question
search_typestringOptionalOverride search method
Sample Request
{ "query": "Tell me about the return policy" }
Stream Event Types
Event typeDescription
search_resultsSearch phase completed, result list included
llm_chunkA text token from the LLM response
cited_sourcesCitation metadata after streaming ends
doneStream complete
200 SSE stream 400 Query too long 429 Quota exceeded

Documents

POST/api/uploadUpload and ingest a PDF or TXT file▶

Chunks, embeds, and indexes the file into Vector DB and BM25.

Request (multipart/form-data)
FieldTypeRequiredDescription
fileFileRequiredPDF or TXT file to ingest
Sample Response
{ "success": true, "document_id": 42, "filename": "product-manual.pdf", "chunks_created": 18, "message": "Document uploaded and processed successfully" }
200 OK 400 Invalid file
POST/api/ingest-urlScrape and ingest content from a URL▶

Fetches a public URL, extracts text, chunks and indexes it like a document.

Request (multipart/form-data)
FieldTypeRequiredDescription
urlstringRequiredPublic HTTP/HTTPS URL to ingest
Sample Response
{ "success": true, "document_id": 43, "title": "Product Landing Page", "url": "https://example.com/product", "chunks_created": 7 }
GET/api/documentsList all ingested documents▶

Returns all documents with metadata: filename, file type, chunk count, upload date.

Sample Response
[ { "id": 42, "filename": "product-manual.pdf", "file_type": ".pdf", "chunk_count": 18, "created_at": "2026-04-01T10:00:00Z" } ]
GET/api/documents/{doc_id}Get metadata for a single document▶
Path Parameters
ParameterTypeDescription

GET/api/documents/{doc_id}/contentRetrieve raw text chunks for a document▶

Returns all stored text chunks for the given document ID.

PUT/api/documents/{doc_id}Update document metadata▶

Updates a document's display label. Does not re-process or re-embed the file.

Request Body (JSON)
FieldTypeRequiredDescription

DELETE/api/documents/{doc_id}Delete a document and all its chunks▶

Permanently removes the document and all associated chunks from Vector DB and BM25 index.

Query Parameters

Path Parameters
ParameterTypeDescription

POST/api/pricingCreate a new pricing record▶

Returns 201 Created on success.

Request Body (JSON)
FieldTypeRequiredDescription
product_namestringRequiredProduct display name
pricenumberRequiredPrice value
currencystringOptionalCurrency code, default IDR
unitstringOptionalUnit label, e.g. unit, kg
skustringOptionalProduct SKU
categorystringOptionalProduct category

Re-embeds all pricing records into Vector DB for semantic search. Run after bulk imports.

Error Codes

HTTP StatusMeaning
400Bad Request — invalid input (e.g. query too long, unsupported file type)
401Unauthorized — API key missing
403Forbidden — invalid API key or insufficient role
404Not Found — resource does not exist
429Too Many Requests — monthly query quota exceeded (Starter plan)
500Internal Server Error — unexpected backend failure

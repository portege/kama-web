VectorDB Viewer

Browse and inspect vector embeddings stored in ChromaDB — view records, metadata, and source distribution.

Restricted Access

The VectorDB Viewer is available only to superadmin.

Overview

ChromaDB stores all vector embeddings that power the semantic search. The VectorDB Viewer lets you inspect what's actually stored — useful for debugging search issues, verifying data sync, and understanding the vector space.

Accessing the Viewer

Access the VectorDB Viewer from two places:

  • Pricing Database → "View VectorDB" button (shows pricing vectors)
  • Product Specifications → "View VectorDB" button (shows spec vectors)

Collection Info

The top section shows overall ChromaDB collection statistics:

  • Collection name — The ChromaDB collection identifier
  • Total vectors — Number of embeddings stored
  • Embedding model — cohere.embed-multilingual-v3
  • Dimensions — 1024

Browse Records

View a paginated list of all vector records with their content and metadata. Each record shows:

FieldDescription
IDUnique vector record identifier
ContentThe text content that was embedded
MetadataAssociated metadata (source document, chunk index, page number, etc.)
SourceOrigin of the vector (document name, pricing, product-spec)
Screenshot: VectorDB record list with content preview, metadata, and source filter

Filter by Source

Use the source filter to view vectors from a specific origin. Sources include:

  • Document names — vectors from uploaded files or ingested URLs
  • pricing — vectors from pricing database sync
  • product-spec — vectors from product spec sync

The source list includes counts, so you can see how many vectors each source contributes.

Record Detail

Click any record to view its full details:

  • Complete text content — the full chunk text
  • All metadata fields — source, document ID, chunk index, page number, etc.
  • Vector ID — the ChromaDB record identifier
Screenshot: VectorDB record detail showing full content and metadata

Pagination

Records are loaded in pages of up to 200 records per page. Use the pagination controls to navigate through large collections.

FAQ Troubleshooting

Pencarian tidak mengembalikan hasil

  • Pastikan dokumen sudah diupload dan diindex
  • Coba turunkan threshold relevansi di Settings
  • Gunakan Debug Search untuk memeriksa skor mentah

Tidak bisa login

  • Kredensial default: admin / admin
  • Pastikan backend berjalan di port 8000
  • Bersihkan localStorage dan coba lagi

Respons LLM gagal

  • Periksa kredensial provider LLM (AWS untuk Bedrock, Google API key untuk Gemini)
  • Periksa Settings → LLM Provider sudah dikonfigurasi dengan benar
  • Periksa log backend untuk pesan error detail

Halaman mengembalikan 403 Forbidden

  • Fitur dinonaktifkan oleh paket aktif. Periksa PLAN_NAME dan flag FEATURE_* di backend/.env.
  • Restart backend setelah mengubah .env.

Query diblokir dengan 429 Too Many Requests

  • Kuota query bulanan (MAX_QUERIES_PER_MONTH) telah habis pada paket Starter.
  • Kuota reset otomatis setiap tanggal 1.
  • Naikkan nilai MAX_QUERIES_PER_MONTH di backend/.env dan restart backend.

Workspace & Label Plan

Di bawah logo BABEH pada sidebar terdapat dua label:

  • Workspace — nama proyek atau deployment, dikonfigurasi via WORKSPACE_NAME di backend/.env.
  • Label Plan — menampilkan paket aktif (Starter, Professional, atau Enterprise) dengan warna berbeda.

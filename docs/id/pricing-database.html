Database Harga

Kelola data harga produk dengan skema dinamis, FTS5 full-text search, dan deteksi rentang harga cerdas.

Field Default

Field default: product_name, sku, category, description, price, currency, unit.

Field tambahan: stock — menampilkan status ketersediaan (Tersedia / Habis) sebagai badge. Nilai stock tidak dikirim ke LLM agar respons tetap ringkas.

Skema Dinamis

Superadmin dapat menambah, mengubah nama, atau menghapus kolom melalui Schema Editor tanpa restart server. Setiap perubahan membuat versi baru dan memicu rebuild FTS/VectorDB secara otomatis.

Tabel Skema Cicilan

Selain tabel harga utama, BABEH menyediakan Tabel Financing Rates untuk menyimpan data cicilan dan kredit. Field yang tersedia: product_name, dp_percent, dp_amount, tenor_months, monthly_installment, interest_rate, otr_price, leasing_company, notes.

Tabel ini dipicu oleh kata kunci cicilan (cicilan, dp, tenor, angsuran, dll) di query pengguna.

Pencarian & FTS

FTS5 mencari berdasarkan bobot: product_name (2.0), category (1.5), sku (1.0), description (1.0).

Deteksi Rentang Harga

Sistem otomatis mendeteksi pola harga dalam query (antara, budget, minimal, sekitar).

Tambah, Edit, Hapus Data

Kelola data harga melalui formulir atau import CSV/JSON.

Sinkronisasi VectorDB

Sinkronkan data harga ke ChromaDB untuk pencarian semantik.

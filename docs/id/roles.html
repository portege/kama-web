Peran & Hak Akses

Referensi lengkap 4 peran dan apa saja yang bisa diakses masing-masing peran.

Ringkasan Peran

PeranTujuanPengguna Tipikal
superadmin Akses penuh — manajemen pengguna, mutasi skema, log aktivitas, VectorDB viewer Administrator sistem
manager Manajemen konten + semua analitik + pengaturan + baca skema Manajer produk
analyst Analitik hanya-baca, riwayat query, pengaturan, debug pencarian Analis data
editor Penulisan konten — knowledge base, harga, spesifikasi produk Penulis konten, data entry

Hierarki Peran

Hierarki
superadmin
├── Semua yang bisa manager lakukan
├── CRUD pengguna (buat/lihat/ubah/hapus pengguna lain)
├── Log Aktivitas
├── VectorDB Viewer
└── Mutasi skema (tambah/edit/rename/hapus field)

manager
├── Semua yang bisa analyst lakukan
├── Semua yang bisa editor lakukan
└── Baca skema (lihat skema, riwayat, diff)

analyst (analitik hanya-baca)
├── Ringkasan, Penggunaan, Wawasan Pencarian, Analitik Pengguna
├── Riwayat Query (lihat + ekspor)
├── Pengaturan (baca + tulis pengaturan LLM)
└── Debug Pencarian

editor (penulisan konten)
├── Manajemen Knowledge Base
├── Manajemen Database Harga
├── Manajemen Spesifikasi Produk
└── Re-index dokumen

Pembatasan Berdasarkan Paket

Selain pembatasan berdasarkan peran, paket langganan menambahkan lapisan pembatasan kedua. Bahkan superadmin tidak dapat mengakses halaman atau endpoint API yang dinonaktifkan oleh paket aktif. Fitur yang dinonaktifkan mengembalikan HTTP 403 dan item sidebar disembunyikan di frontend. Lihat Paket Langganan untuk matriks lengkap.

Halaman Financing Rates ditambahkan ke daftar halaman konten — dapat diakses oleh superadmin, manager, dan editor.

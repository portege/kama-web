Max Query LengthBatas karakter per query pengguna (10 – 200, default 100). Query melebihi batas akan ditolak dengan HTTP 400.
Max Input TokensBatas token konteks yang dikirim ke LLM (10 – 900, default 600). Prompt dipotong jika melebihi batas (≈4 karakter/token).
Max Output TokensBatas token yang boleh dihasilkan LLM (1 – 1200, default 900). Memetakan ke max_new_tokens (Nova) / max_tokens (Claude) / maxOutputTokens (Gemini).

Tips Tuning

Temperature rendah (0.1–0.3) untuk jawaban faktual, tinggi (0.7–0.9) untuk jawaban kreatif.

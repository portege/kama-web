Manajemen Pengguna

Buat, edit, dan hapus akun pengguna — kelola peran dan hak akses.

Akses Terbatas

Hanya superadmin yang dapat mengelola pengguna lain.

Daftar Pengguna

Tabel pengguna dengan username, peran, email, tanggal dibuat, dan aksi.

Buat Pengguna Baru

Isi username, password, email, nama lengkap, dan pilih peran.

Edit Pengguna

Ubah data pengguna atau ganti peran mereka.

Ubah Password

Semua pengguna dapat mengubah password mereka sendiri. Batas bcrypt: 72 byte.

Widget Tertanam

Pasang widget pencarian BABEH di halaman web manapun — panel mengambang yang memberikan pencarian AI tanpa dependensi tambahan.

Instalasi

Dua cara pemasangan: Script + JS Init, atau Auto-Init via data attributes.

Metode A: Script + JS Init

HTML
<div id="kbaas-widget"></div>
<script src="js/kbaas-widget.js"></script>
<script>
 KBaaSWidget.init({
 apiUrl: 'https://domain-anda.com/api',
 apiKey: 'api-key-anda'
 });
</script>

Metode B: Auto-Init via Data Attributes

HTML
<div id="kbaas-widget"
 data-api-url="https://domain-anda.com/api"
 data-api-key="api-key-anda">
</div>
<script src="js/kbaas-widget.js"></script>

Opsi Konfigurasi

OpsiDeskripsi
apiUrlURL API backend untuk pencarian
apiKeyAPI key (dikirim via header X-API-Key)
containerIdID elemen HTML untuk mount widget
apiBaseUrlURL dasar untuk health check

Metode API

init(), search(), clear(), configure(), getConfig(), isInitialized()

Tema & Dark Mode

Otomatis mengikuti preferensi sistem, atau toggle manual Light/Dark.

Responsif

4 breakpoint: >768px, ≤768px, ≤480px, ≤360px.

Shortcut Keyboard

Ctrl + Enter — submit pencarian dari textarea.
